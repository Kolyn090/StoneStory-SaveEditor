# StoneStory Save Editor


## 🪨 Intro

Are you tired of doing the Referral Code everyday? Well, I might have a nice solution for you!

This standalone GUI app allows you to instantly obtain all Cosmetics, in less than two minutes! It also allows you to edit your Save File, but I probably wouldn't recommend that if you still want to have fun with the game...

**Beware that editing the save file is possible for you to get banned from the game. Understand the risk before use.**

## 🔰 Tutorial

1. Download the latest release. Unzip it.

2. Inside the folder, you will see a ton of files, but you should really only be focusing on `StoneStorySaveEditor.exe`. Double-click it to open the GUI app. 

3. Obtain your game save file. You can find it in game home page → Options → Saved Games → Export → Clipboard.

4. **Save your current game save file to somewhere you remember.** If you get errors later on you can recover with it. **⚠️ Always be sure you have kept an original copy. If you lose your game progress nobody can help you.**

5. Paste your save in Save Editor. Click 'Next'.

6. Now you should be in 'Decrypted JSON Editor'. You can start editing your save file in the textbox. You can use the top search bar to find by text (try 'inventory') but the search bar is a little buggy. **You can click 'Unlock All Cosmetics' to instantly add all Cosmetics to your save file.** (If you notice something is missing please let me know)

7. After you are happy with it, click 'Export' and a new complete game save will be displayed in the bottom textbox. Copy everything in it.

8. Import your new file in game. Home page → Options → Saved Games → Import → Clipboard.
